# 银发学习平台 (Silver Age Learning Platform)

## 项目概述
银发学习平台是一款专为老年群体设计的数字化学习与生活服务应用。项目旨在通过适老化设计、游戏化互动和社区化运营，帮助老年人跨越数字鸿沟，享受丰富多彩的退休生活。平台集成了在线课程、益智游戏、社区交流和积分商城四大核心模块，打造了一个“学、玩、聊、购”的一站式生态圈。

## 🛠 技术栈

### 前端架构
- **核心框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **路由管理**: Vue Router 4
- **样式方案**: Tailwind CSS (Utility-first CSS)
- **图标库**: Material Symbols (Google Fonts)

### 开发环境
- **语言**: JavaScript (ES6+) / HTML5 / CSS3
- **包管理**: npm
- **代码规范**: ESLint + Prettier

## ✨ 创新技术点与适老化设计

### 1. 深度适老化交互设计 (Age-Friendly UX)
- **大字体与高对比度**: 全站采用 WCAG 2.1 AA 标准的高对比度配色，正文最小字号 16px，按钮触控区域不小于 44x44px。
- **极简操作流程**: 摒弃复杂的下拉菜单和多级跳转，核心功能（如课程报名、游戏开始）均采用“一键直达”设计。
- **清晰的视觉反馈**: 所有可交互元素在悬停、点击时均有明显的缩放、变色或阴影动效，消除操作不确定性。

### 2. 沉浸式益智游戏引擎 (Brain Training Hub)
- **前端微内核架构**: 游戏专区采用组件化微内核设计，实现了**记忆配对**、**数字华容道**、**简单数独**三款游戏的纯前端逻辑封装。
- **本地化状态管理**: 游戏进度、计分、倒计时完全在客户端闭环运行，零延迟响应，并在刷新页面时自动重置，降低服务器压力。
- **自适应难度算法**: 针对老年人认知特点，定制了简化版规则（如 3x3 华容道、4x4 数独），并提供即时错误提示与鼓励机制。

### 3. 动态响应式社区系统 (Reactive Community)
- **多媒体内容流**: 实现了支持图文混排、标签过滤的信息流组件，图片采用 CSS Grid 自适应布局，自动处理单图、双图、多图的展示效果。
- **实时模拟交互**: 完整的点赞、评论、发布功能均通过 Vue 响应式数据模拟了真实的 CRUD 操作，提供无缝的“即时通讯”体验。

### 4. 积分激励闭环体系 (Gamification Ecosystem)
- **统一积分账户**: 打通了“学习获取积分”与“商城消耗积分”的数据流，构建了完整的激励闭环。
- **防超卖前端逻辑**: 商城模块内置了库存预扣与余额校验逻辑，并在前端模拟了事务性的兑换流程，包含二次确认与成功回执。

## 📦 核心功能模块

### 🏠 首页 (Home)
- **动态推荐**: 基于 `v-for` 渲染的热门课程卡片，支持快速跳转。
- **快捷注册**: 包含倒计时验证码模拟的注册卡片，提供流畅的 onboarding 体验。
- **全局导航**: 响应式顶部导航栏，集成用户个人中心入口。

### 📚 优质课程 (Course)
- **多维度分类**: 支持“传统技艺、智能设备、健康养生”等六大类课程筛选。
- **详情路由**: 实现了 `/course/:id` 动态路由，支持课程详情页的深层链接访问。

### 🧩 发现与游戏 (Discover)
- **游戏中心**: 集成全屏游戏浮层，提供无需跳转的沉浸式游戏体验。
- **兴趣小组**: 展示活跃的线下/线上社群，支持查看详情与加入申请。

### 💬 社区广场 (Community)
- **内容发布器**: 支持图片预览、标签选择的富文本发布组件。
- **互动信息流**: 高度还原社交 App 的点赞、评论与分享体验。

### 🛍️ 积分商店 (Store)
- **商品兑换**: 包含库存管理、积分扣除、历史记录查询的全流程模拟。
- **分类搜索**: 支持实时关键词搜索与商品类目过滤。

### 👤 个人中心 (Profile)
- **信息管理**: 支持头像上传预览、昵称修改与密码重置。
- **系统设置**: 包含隐私权限控制、主题切换与消息通知中心。
